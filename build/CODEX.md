# Результаты сборки

Каталог предназначен для сгенерированных PDF, изображений, промежуточных файлов и отчетов. Содержимое может быть пересоздано инструментами из `tools/`.

Не вносите сюда смысловые правки и не считайте эти файлы источником истины. Перед коммитом включайте только действительно требуемые артефакты.
