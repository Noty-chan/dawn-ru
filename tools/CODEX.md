# Инструменты проекта

В этой папке находятся сценарии сборки, преобразования и контроля качества. Изменяйте инструмент вместе с проверкой его результата, а не только успешного завершения процесса.

Не храните здесь вручную подготовленные результаты: они должны попадать в предназначенные каталоги сборки.
