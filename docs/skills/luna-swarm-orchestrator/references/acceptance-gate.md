# Шлюз приёмки

## Diff и владение

- Работа начата от объявленного SHA.
- Изменены разрешённые файлы; shared/generated-файлы имеют одного владельца.
- Нет артефактов, секретов и изменений защищённых пользовательских каталогов.
- Coder и Destroyer не писали одновременно в один worktree/seam.

## Инварианты

- Version, undo, journal и persistence имеют одного writer.
- Helper не повторяет commit authoritative writer.
- Validator получает настоящие before/after.
- Ошибка сохраняет исходное состояние семантически неизменным.
- Transient snapshots и внутренние очереди не попадают в Scene/export/DOM.

## Полный путь

- Runtime реально загружает модуль; offline/service-worker manifest обновлён.
- UI вызывает новый путь, старый mutator не срабатывает следом.
- Sanitizer сохраняет нужные typed fields.
- Reducer повторно вычисляет доверенные значения.
- Reload, export/import, stale и replay проверены раздельно.
- Player projection скрывает приватное состояние.

## Уровни доказательства

- Unit проверяет чистую логику.
- Integration использует настоящие validator/writer/projection/storage boundaries.
- Browser открывает настоящую страницу, роль, пустое и заполненное состояние.
- Network использует два клиента, reconnect и reload.

Нижний уровень не заменяет верхний. Unit обычно подтверждает foundation;
integration — connected; verified требует релевантного реального пути.

## Частые ложные успехи

1. Helper протестирован, но не загружается приложением.
2. `validate: () => true` подтверждает лишь вызов.
3. Helper и UI оба увеличивают version или добавляют undo.
4. Локальный UI сохраняет поле, sanitizer его удаляет.
5. Table backup работает, hero export теряет данные.
6. `innerHTML` проходит, кнопка не работает.
7. Service worker отдаёт старую сборку.
8. Один клиент назван синхронизацией.
9. Отчёт пишет verified при наличии релевантного `not-run`.
10. Параллельные агенты перетирают общий integration file.

## Решение интегратора

- принять с подтверждённым статусом;
- принять изолированно как foundation;
- вернуть Coder на узкую коррекцию;
- исправить малый seam локально;
- blocked при реальной внешней или архитектурной зависимости.
