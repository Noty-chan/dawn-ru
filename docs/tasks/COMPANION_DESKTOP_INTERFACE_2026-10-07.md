# Стол: инициатива и следующие правки · 07.10.2026

База: `main` 8d31815. Поручение: реализовать портретную инициативу слева;
исследовать пункты 2–4 тремя агентами; убрать временное «Тестирование».

## Реализовано

- Новая настольная оболочка: колонка инициативы 64 px, портреты 44 px.
  Золотая рамка и стрелка обозначают текущий ход; голубой контур — выбор;
  галочка — завершённый ход; минус — участника вне боя. Полное имя и статус
  доступны в подсказке и доступном названии кнопки.
- При левой панели: портреты занимают компактный блок максимум двух рядов
  над панелью. При двух панелях скрываются. После закрытия возвращаются.
- Длинная лента прокручивается к текущему участнику при смене хода или режима
  размещения. Обновление ресурсов сохраняет ручную прокрутку. Прокрутка ждёт
  актуальный DOM и видимую геометрию, включая возврат из других разделов.
- Исправлен неверный CSS-класс режима «Фокус»; пустой состав не оставляет колонку.
- Убраны ссылка «Тестирование», страница галереи, её JS/CSS, precache и тест
  удалённой галереи. Pages больше не публикует папку прототипов. Черновики
  сохранены в `apps/companion/prototypes`; исправления маршрутов SW сохранены.

`tests/syntax.mjs` и `git diff --check` прошли.
Полный `npm test` также завершился с exit 0. После изменения состава тестов

хода/выбора, скрытые акторы игрока, завершённые и повторные ходы, отсутствие

Локальный браузер, отдельное хранилище, 16 участников:
1280×720 и 1152×700; одна/две панели; выбор другого портрета не меняет текущий

горизонтального переполнения ленты нет; «Фокус» скрывает и возвращает её;

   двухколоночная сетка текстового меню. Действия/Техники и Лист — для героев;
   Приёмы и Профиль — для НПС. Игроку: свой герой — Действия/Лист/Цель;
   чужой герой и НПС — Профиль/Цель. Ведущему дополнительно доступны ЗД,
   Эффекты и служебные команды. Отличать НПС по профилю, а не только команде.
   Повторять каноническую проверку права в обработчике.

4. **Нижняя панель.** Переносы и `margin-left:auto` служебной группы создают
