# Ручной стол: быстрый отклик и компактные controls (2026-10-09)

## Что изменено

- Оверлей токена — только ПКМ. Hover показывает существующую подсказку; удержание для перетаскивания закрывает HUD и подсказку. Кнопки 40 px, дополнительные интервалы, большой редактор здоровья отдельно от мини-индикатора.
- Ручные typed команды немедленно отображаются локально и отправляются без ожидания следующего 200 ms такта. Подтверждённая сцена остаётся отдельной; стабильные event ID предотвращают повторное применение, отказ откатывает предварительное представление. Сетевой RPC всё ещё может занимать секунды.
- Быстрые ручные команды исключены из общего 450 ms подавления двойного клика. Pending metadata snapshot сохраняется при отображении предварительных ресурсов.
- Бросатор: компактный диалог и четыре кнопки Атрибутов подключённого локального листа. Число D6 остаётся редактируемым.
- Часы: группы прогресса/угрозы/счётчиков, заполненные секции и кнопки +/−.
- Напряжение доступно Нарратору в верхней полосе. ОД, Фокус и Раны выбранного участника — в нижней полосе; набор видимых счётчиков настраивается отдельно для каждого токена локально. Изменения обновляют связанные локальные листы, а не только активный лист.
- Footer не заменяется при неизменном содержимом. Перерисовка защищена от native change при удалении dirty inputs; пустое поле не превращается в ноль.

## Проверка

Полный `npm test` завершился `FINAL_EXIT=0` (локальный журнал output/table-responsive-ui-release-20261009.log). Целевые тесты проверяют replay, отказ, неподвижное confirmed state, HUD без hover/left-click и геометрию 648 случаев. После заключительных исправлений дополнительно пройдены manual-token-counters, manual-optimistic-snapshot, table-manual-workspace, table-manual-surfaces, lionwing-recovery-stress и syntax.

Браузер: только Disposable UI MVP QA 20261009 на существующем Supabase. Проверены ПКМ HUD, отсутствие HUD при выборе из инициативы, два последовательных изменения Ран 1→2→3 без ожидания RPC, предварительная проверка ввода ОД через fill (native change отдельно моделируется в тесте), Атрибуты листа 4/3/2/2 и выбор Таланта → 3D6, Напряжение 7 настоящим вводом с клавиатуры с подтверждением после reload, часы прогресса 1/6. Также проверены немедленное включение/снятие личной отметки, сохранение скрытого Фокуса после reload только у выбранного NPC и доступный Фокус у второго токена. Меню настройки раскрывается над footer и не вызывает reflow. Скриншоты находятся в ignored output/.

## Ограничения / продолжение

- Это локальное предварительное отображение, а не устранение физической задержки сервера. Ошибки и подтверждения остаются видимыми в сетевой панели.
- Не заявлена нагрузочная или многопользовательская приёмка этой порции UI. Предыдущая реальная сетевая MVP приёмка описана в MANUAL_TABLE_MVP_RELEASE_2026-10-09.md.
- Принятое пользователем ограничение Supabase Broadcast после отзыва участия осталось.
- QA стол не удалён: ранее заданный вопрос о постоянном удалении остаётся без ответа.
- Для локальной проверки нужен новый query build для scripts: старая тестовая HTML-копия использовала закешированные URL и давала ложные результаты.


## Дополнение: раунд и Напряжение

По последнему соглашению положительное изменение ручного раунда увеличивает Напряжение на столько же. Это выполняется атомарно внутри round-команды: replay не даёт двойного повышения, остальные боевые границы, расходы ОД и обработки техник не запускаются. Ручная корректировка Напряжения сохранена; её предел согласован с нормализацией Сцены (999).

Кнопки footer получили более мягкий фон/рамки, а шаговые кнопки ресурсов — немного больше места. Hover меняет только цвет/рамку.

Целевые policy/workspace/network/clock/dice/counter/snapshot/syntax тесты PASS. В браузере клавиатурная корректировка Напряжения 7 сохранилась после reload; следующий раунд с клавиатуры 1→2 дал 7→8; затем мышью 2→3 дал 8→9 немедленно. В локальном QA отключён только баннер сравнения build (bootstrap v=dev), который иначе перекрывает кнопки из-за искусственного build URL. Production баннер не менялся.
