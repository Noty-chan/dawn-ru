# Передача задач

Папка содержит снимки контекста и задания для продолжения работы. Они помогают быстро войти в тему, но могут отставать от текущего состояния ветки.

Новый агент должен сначала проверить ветку, `git status`, последние коммиты и ближайшие `CODEX.md`, затем подтвердить предположения по коду и тестам.
