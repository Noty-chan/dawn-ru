# LionWing: готовность альфа-стресс-теста и контракта ОД

## Готово

- Новый профильный LionWing NPC получает `baseAp: 3` и `ap: 3` в начале своего
  Хода; `crowd` и `enemy.modifier.*` получают `0`.
- Явно заданное значение особого призыва сохраняется, включая случай, когда
  задан только `baseAp`.
- Копия канонического LionWing пресета сохраняет редакцию и материализует
  обычных NPC с 3 ОД. RU-v0.9 и старые записи с явными 2 ОД остаются на 2 ОД;
  миграции старых столкновений нет.
- Сохранённая новая пользовательская расстановка получает маркер редакции,
  поэтому последующая нормализация не возвращает её к legacy default.

Автоматический acceptance-сценарий
`apps/companion/tests/lionwing-alpha-stress.mjs` создаёт героя из производных
характеристик, несколько NPC, массовку и составного босса, затем проходит
Turn start, трату ОД базовыми Атаками, окно Реакции, урон, Эффект и сброс Раунда.
Регрессия `lionwing-gm-ap-contract.mjs` отдельно проверяет builtin-копию,
новую пользовательскую запись и политику старых пресетов.

## Проверка

- `npm --prefix apps/companion run test:alpha-stress`
- `npm --prefix apps/companion test`

## Оставшиеся ручные шаги

В браузере открыть LionWing, создать героя, сохранить новую расстановку,
скопировать «Бегуны Дюн-изгои · ручной стресс-тест» и провести несколько
Раундов через Пульт Нарратора, сверяя 3 ОД обычных NPC, нулевые ОД массовки и
Модификатора и общую Полосу Здоровья составного босса. Правила конкретных
вражеских Атак остаются ручными до отдельного пакета автоматизации.
