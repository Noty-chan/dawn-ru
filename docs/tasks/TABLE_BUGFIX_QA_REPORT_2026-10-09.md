## Дополнительные наблюдения, не выданные за закрытые сценарии

1. При native переименовании NPC во время чужого resource update ввод потерял focus; `pressSequentially` остановился, а имя стало частичным **QA As**. Это отдельный кандидат P2 по текстовым draft, подтверждённый DOM, но без нового paired screenshot/чистой повторной воспроизводимости после K2. Не считается доказательством VAL05 PASS.
2. Попытка P опубликовать вторую копию листа (QA Hero B) получила на G сообщение «Действие игрока задержано: Снимок не может менять боевое состояние участника». Два героя кампании в итоге созданы обычными путями P/G. Не объявляется новым багом без выяснения договора назначения одного героя игроку; список owner/capability этим не проверен.
3. Некоторые screenshot calls возвращают кадр до paint нового DOM. Это ограничение фиксации доказательств, не дефект сайта. Несовпадающие кадры не использованы как PASS соответствующего состояния.

## Известные ограничения и состояние после остановки

- Принятое пользователем **Supabase old-socket revocation**: отозванный участник может продолжать отправлять **и получать** Broadcast через старое открытое соединение до reconnect. В этом аудите отзыв не воспроизводился; прежний FAIL не переименован в новый PASS. Сервер не менялся.
- `TABLE_START_RULES_UNAVAILABLE`, полный backlog техник, freeplay atomic WIP и мобильная эстетика не объявлены выполненными или новыми выпускными блокерами этого manual-аудита.
- QA-кампания **не удалена**. Перед остановкой был применён встроенный пресет; исход Undo неизвестен. Для следующего сеанса сначала проверить её фактическое состояние, не повторять намерение вслепую.
- В G язык возвращён RU, next включён; тестовое разрешение left panels / «Все панели слева» не восстановлено из-за K2. Это локальные настройки. В P viewport override остался1152×700 до остановки. Очистка/восстановление требует нового доступного browser сеанса; автоматического обхода остановки не делалось.
- Существующие пользовательские кампании не открывались для проверок после выхода из первоначально открытой. Новая кампания и новые QA-листы сохранены; постоянное удаление не выполнялось.
- Следующая полноценная приёмка должна иметь G+P1+P2, рабочую обработку confirm, покрыть остатки BLOCKED и отдельный rules smoke. Из данного документа нельзя получить «37 PASS».
