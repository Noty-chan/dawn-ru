## Самые важные подтверждённые ловушки

1. Линейка уже считает дистанцию, но носитель числа скрыт CSS. Hover Player
   использует GM `Scene.tool` вместо `activeSceneTool`. Исправить обе части.
2. Базовые controls перемещаются в Map, а выбор area/wall/marker открывает rail.
   Не оставлять быстрый «инструмент» ссылкой на боковой редактор.
3. HUD geometry имеет реальные пересечения с токеном шириной 150 px.
   Нужен invariant каждого интерактивного rect, не доверие комментарию про hole.
4. Generic erase удаляет акторов. Нужен object-only инструмент с явным preview.
5. Старый sceneControlMode manual принудителен для LionWing и локален.
   Он **не отключает правила**, поэтому не мигрировать его в настоящую manual policy.
6. `move(placement:true)`, `correct`, `prepareDestroy` не являются безопасными
   ручными примитивами: вызывают дополнительные игровые процедуры.
7. Воспроизведено при старом manual: Focus 10→2/AP 0→3 на turn-start;
   Regen HP 5→10 на turn-end; Gas при placement даёт Ослабление и consequence.
8. Старые #new-scene/scene-reset лечат/очищают данные. Новый вход в бой требует
   отдельного атомарного контракта с кратким показом изменяемых данных.
9. Нейтральные линейка/показ/пинг нельзя включать через changeSceneTool,
   который отменяет pending draft. Они обязаны сохранять подготовленную атаку.
10. `lwGeometrySceneIdentity` содержит скрытые actor IDs. Для показа нужен
    публичный epoch/space, whitelist координат без секретных сущностей.
