Приоритет для следующего внедрения: гаджеты в composer; каноническая таблица цели на Ступенях 3+; сохранение оговорённого Риска/Награды запроса; закрытие альтернатив после решения; атомарная оплата после успешного commit. Боевой пульт должен выводить действия до текстов техники, а справка — сохранять исходное действие и фокус.

Черновики кликабельные, но это **foundation** с демонстрационными данными. Цветовая гамма — существующая production-палитра по уточнению пользователя. Для сравнения меняются структура и поведение, а не цвета. Исходные предложения светлой/зелёной гаммы отклонены.

В production изменены только порядок вкладок (Герой → Инструменты → Стол → Правила → Справочник) и компактное меню токена. HUD показывает «Действия / Профиль / Цель / Ещё», явное изменение ЗД, сохраняет фокус при обновлении и закрывается без оплаты по Escape. Права, сеть и игровая механика не изменены. Остальные находки пока не реализованы.

Проверка: полный `npm test` exit 0; текущие HUD и pointer regression tests; CUA на тестовой Сцене с отдельным хранилищем, 1440/390px. Windows symlink и optional legacy Raasha fixture пропущены существующим набором тестов. Нарратор + два реальных сетевых игрока **not-run**, полноценная проверка игры через Стол отложена по запросу пользователя.
