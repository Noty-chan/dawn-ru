# Запуск нового стола «По правилам» · 09.10.2026

База — main после manual PR #16 (`4aee45a`) и исторического QA PR #15 (`5d15309`). Ветка исправления: `codex/rules-table-start-20261009`, изолированный checkout `Dawn-rules-qa`. Чужие checkout и кампании не изменены, сервер и SQL002 не затронуты.

## Исправленная причина

Все новые сцены создавались manual, UI возвращал выбор rules назад с сообщением «подключение ещё готовится», а ядро безусловно отклоняло start-rules. Теперь выбор «По правилам» открывает отдельное окно выбора первого участника с preview ОД/Фокуса. Отмена/Escape оставляют стол manual. Подтверждение отправляет типизированную команду Нарратора, проверяет версию/epoch и запускает канонический первый Ход LionWing.

Команда атомарно меняет policy, устанавливает Раунд 1/Напряжение 0 и передает расчет стартового Фокуса, ОД и начальных границ действующему ядру. ЗД/Раны/Стресс/Влияние, позиции, карта, пользовательские записи и ручные часы сохраняются. Не использованы старый scene-reset или возобновление frozen runtime. Общая версия повышается один раз; receipts первого Хода и внешней команды сохраняются, точный повтор не расходует ресурсы и не начинает второй Ход.

Потеря роли/смена комнаты или policy закрывают окно, обновление версии делает подтверждение недоступным. Неподтвержденная сетевая очередь также препятствует запуску. Игрок не может материализовать start-rules через свой intent. Новые подписи и журнал запуска входят в RU/EN каталоги.

## Граница: новый бой, не возобновление замороженного

**Поддержан старт нового подготовленного manual-стола LionWing.** Если стол содержит уже начатый ранее бой, turnSerial, собственные Ходы или очередь дополнительных Ходов, запуск отклоняется. Также блокируются ауры и временные автоматические Эффекты/источники/ресурсы/часы; допустимы ручные и постоянные записи без старой временной границы. Судьба старых автоматических сроков/источников еще не реализована; данный diff не разрешает переключать arbitrary frozen campaigns. Существующие rules-сцены продолжают идти через прежний движок.

Первый участник должен удовлетворять каноническому turnStartStatus. При наличии героев первым ходит доступный герой; массовка и модификаторы не имеют собственного Хода. Это не свободный выбор любой команды вопреки правилам.

## Реальный UI: localhost, не production и не harness

Обычный index.html, IAB, новый origin `http://127.0.0.1:8891`, LionWing, next, Нарратор. Никаких инъекций store/localStorage, импортов rules snapshots, модификации DOM/CSS для обхода, SDK/RPC или живого Supabase. Участники добавлены штатными формами.
