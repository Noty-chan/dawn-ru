# Рабочая документация DAWN

Эта папка содержит действующие спецификации и входные данные для генераторов. Старые отчёты, аудиты и передачи задач собраны в архивах [августа](../archive/2026-08-companion-reports/README.md) и [сентября 2026](../archive/2026-09-task-reports/README.md). Архив фиксирует состояние на дату отчёта и не служит списком текущих задач.

## С чего начать

- **Текущий приоритет — ручной стол на ПК:** [checkpoint 7 октября](MANUAL_TABLE_HANDOFF_2026-10-07.md), затем [продолжение 8 октября](MANUAL_TABLE_CONTINUATION_2026-10-08.md). Затем [последний подхват](MANUAL_TABLE_RESUME_2026-10-08.md): HUD, ручные панели, история и оставшиеся проверки. Серверная миграция всё ещё не применена.

- **Полный октябрьский список UI/Стола:** [объединённый backlog](COMPANION_COMPLETE_BACKLOG_2026-10-07.md). Он соединяет договор отдельной ветки с аудитами 5–6 октября; не заменять его коротким списком последнего PR.

- **Правила и редакция:** [граница редакций](../../apps/companion/EDITION-BOUNDARIES.md), затем [архитектура компаньона](../../apps/companion/ARCHITECTURE.md) и ближайший `CODEX.md`.
- **Готовность автоматизации:** [реестр](../../apps/companion/LIONWING-AUTOMATION-REGISTRY.md) и [генерируемый отчёт](../../apps/companion/AUTOMATION-READINESS.md). Проверяйте фактический код и тесты перед утверждением о готовности.
- **Результаты проверок конкретной сборки:** [контракт запуска](../../apps/companion/AUTOMATION-VERIFICATION.md). Реализация, исторический аудит и актуальный результат CI учитываются отдельно; результаты не коммитятся как вечные успехи.
- **Интерфейс стола:** [подтверждённый бриф](VTT_INTERFACE_REDESIGN_BRIEF.md), [критерии приёмки](VTT_INTERFACE_ACCEPTANCE.md), [боевой сценарий](../../apps/companion/BATTLE-CYCLE-QA.md).
- **Сетевой слой:** [README Supabase](../../supabase/README.md) и миграции; применённое состояние базы проверяйте отдельно от истории Git.
- **Исторический контекст LionWing:** [аудит от 20 сентября](LIONWING_PROJECT_AUDIT_2026-09-20.md) и [снимок передачи от 21 сентября](../archive/2026-09-task-reports/LIONWING_LATEST_HANDOFF_2026-09-21.md). Их TODO требуют повторной проверки на текущем `main`.

Файлы `lionwing-rule-families.json` и `lionwing-technique-requirements.review.json` остаются здесь: генераторы читают их по фиксированным путям. Новые одноразовые отчёты помещайте в архив с датой, а в этой папке оставляйте только документы, по которым принимаются текущие решения.
