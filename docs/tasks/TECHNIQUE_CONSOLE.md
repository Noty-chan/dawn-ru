# Пульт техник LionWing — состояние и продолжение

Обновлено 2026-10-01. Разработка ориентирована на LionWing. Пользователь решил
постепенно выводить 0.9 из использования; сейчас она остаётся архивной
совместимостью. Её удаление или блокировка требуют отдельной миграции.

## Что изменено

- Пульт различает количество семейств и изученных уровней, работающую,
  выключенную и ручную автоматику. Есть атомарное включение доступных правил.
- Английские названия, оригинал и сведения об источнике свёрнуты. Описание,
  объяснение использования и основные команды показываются по-русски.
- Управление областями Бомбардира и Ученика звёзд находится у этих техник.
  Параметры разных форм изолированы; обычное действие не забирает Фокус
  из соседней формы. Выбор клетки и отмена не списывают ресурсы.
- Список настройки теперь включает модификаторы действий и существующие
  команды Ученика звёзд. Раньше они работали при прямом изменении флагов,
  но отсутствовали в списке, разрешённом командой `automation`.
- Недостающие часы «Сосулька» создаются при включении Криоманта II или при
  действии с восстановленными флагами. Повторное включение сохраняет сегменты;
  действительное начало Сцены устанавливает канонический начальный счётчик.
- Исправлено падение экрана цепочки при передаче ID вместо объекта действия.
  Название нативной атаки берётся из `sourceActionId` и русского каталога.

## Что остаётся

Исправление вывода от 2026-10-01: все три уровня «Мастера оружия» уже были
реализованы по canonical EN, странице 79, в общем событийном ядре. Нативный
маршрутизатор LionWing обходил этот код, а пульт ошибочно считал его ручным.
Добавлен явный мост нативной команды к проверенной реализации и кнопки
Вооружений/Завершения с выбором клеток. Статус учитывает исполняемые правила
общего ядра; отдельное включение этого семейства не требуется.
Для остальных семейств проверить специальные активные формы: общий текст
«Как использовать» не заменяет пульт каждого нестандартного правила.

## Проверки и важные границы

- Обязательная команда: `cd apps/companion` → `npm test`.
- `tests/lionwing-technique-surface.mjs`: реальное включение, пакет с неизвестным
  правилом, отсутствие расхода при настройке, Зарядка → Завершение по линии,
  часы, точный повтор, повторное включение и восстановленные флаги.
- `tests/lionwing-destination-contracts.mjs`: изоляция вложенного поля Фокуса.
- `tests/lionwing-provenance.mjs`: настройки, включая варианты области,
  явно ссылаются на канонический уровень и проверенный SHA-256.
- В локальном браузере пройдены включение и перезагрузка, отмена области,
  Зарядка, подсвеченный выбор линии, перезагрузка ожидающей атаки и применение
  урона: 3 → 1 → 0 ОД, расход выбранных 2 Фокуса, манекен 30 → 26 ЗД.
- Это проверка локального интерфейса. Нагрузка на живой Supabase несколькими
  одновременными соединениями этим проходом не проверена.

## Правило для следующих реализаций

Готовность отображения берётся из исполняемых регистраций
`DAWN_LIONWING_ADAPTERS.coverage`, а включение — из того же списка `list`.
Общая сгенерированная карта не должна создавать отсутствующий обработчик.
Для нового подключения тест должен сначала включить правило командой ядра,
затем выполнить его игровой путь. Прямое присваивание `automation: true`
не проверяет доступность правила пользователю. Инициализация недостающего
состояния не должна повторно выдавать бонусы начала Сцены или стирать прогресс.
