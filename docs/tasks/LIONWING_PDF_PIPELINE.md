# Подготовка русской PDF DAWN LionWing

Дата начала: 2026-09-05.

## Назначение

Новая книга собирается как отдельный артефакт LionWing, а не как обновление PDF редакции 0.9. Источник русского текста - проверенный перевод системных глав в `source/translation/`; английский LionWing остается неизменяемым источником сверки. Локальный лицензионный PDF не копируется в репозиторий и не становится входом, обязательным для базовой текстовой сборки.

## Первый воспроизводимый артефакт

Команда:

```powershell
python tools/layout/build_pilot_pdf.py lionwing-proof
```

Результаты:

- `build/pdf/dawn-ru-lionwing-system-proof.pdf` - рабочая PDF системных глав;
- `build/tmp/pdfs/lionwing-system-proof/page-*.png` - изображения всех страниц для визуальной проверки.

Proof намеренно не использует арт-кропы и координаты редакции 0.9. В него входят введение и все переведенные системные главы: универсальные правила, создание персонажа, свободная игра, структурированный бой, Техники, инструменты Нарратора, NPC, ставки и модификаторы.

## Что пока не входит

- фронтматтер, новое оглавление и финальные титры LionWing;
- страницы сеттинговых примеров, еще не прошедшие отдельный переводческий проход;
- иллюстрации и декоративные элементы, координаты которых нужно заново снять с LionWing;
- финальная пагинация, закладки и перекрестные ссылки;
- релизный файл в `release/`.

Эти исключения нужны, чтобы текущий proof не выдавался за законченную книгу и не смешивал страницы разных редакций.

## Следующие этапы

1. Зафиксировать LionWing-структуру разделов и новое оглавление.
2. Добавить отдельную карту иллюстраций и подписей без переиспользования координат 0.9 вслепую.
3. Вернуть специальные шаблоны: открывающие страницы, глоссарий Способностей, карточки Техник, NPC и боевые схемы.
4. После перевода сеттинговых примеров включить их в полный корпус.
5. Добавить отдельный строгий QA-профиль LionWing: метаданные, закладки, ссылки, шрифты, пустые страницы и визуальный контакт-лист.
6. Только после полного визуального прохода выпускать версионированный файл в `release/`.

## Граница безопасности

- `source/original/Dawn - A Diceless Fantasy TTRPG.pdf` остается источником редакции 0.9 и не используется как канон LionWing.
- Локальный LionWing PDF допустим только для сверки и подготовки разрешенных визуальных элементов; он не коммитится.
- Английский канон и стабильные ID не редактируются ради русской верстки.
