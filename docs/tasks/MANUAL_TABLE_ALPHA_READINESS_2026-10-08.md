# Ручной стол: готовность к альфе, 8 октября 2026

## Решение

Закрытая **локальная альфа ручного стола** пригодна для проверки игрового цикла на ПК. **Сетевой выпуск и merge main пока не подтверждены**: серверная приватность и многоклиентные проверки остаются воротами выпуска. Автоматизированный бой нельзя считать полностью проверенным по результатам ручного стола.

## Обязательное перед сетевой альфой

1. `supabase/migrations/202610080001_manual_table_public_records.sql` не применён. Проверить миграцию и серверное исключение скрытых clocks/counters/owner metadata из public records. JS-фильтр не заменяет серверную приватность. Live Supabase и пользовательские столы для этой задачи не трогать.
2. Изолированный authenticated RLS/Realtime прогон: GM/player, epoch/room change, reconnect, rejected/retried writes; затем5 комнат×5 клиентов. Локальные mocks и PGlite не закрывают этот пункт.
3. N01–N03: приватный ephemeral transport показов с проверяемым автором и назначенным сервером цветом. Не писать жесты в Scene, Action outbox или DB rows. До проверки shared инструменты сохранять выключенными.
4. Manual→rules: атомарный initializer с preview/cancel, первым участником, сохранением ручных позиций/ресурсов. Сейчас `TABLE_START_RULES_UNAVAILABLE` намеренный guard; его обход не является реализацией.
