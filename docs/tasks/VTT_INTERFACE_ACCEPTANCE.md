# Приёмка интерфейса стола DAWN

Дата последнего прохода: 2026-08-31  
Ветка: `codex/vtt-interface-redesign`

Этот файл проверяется вместе с `VTT_INTERFACE_REDESIGN_BRIEF.md`. Он фиксирует не обещания по макету, а фактически пройденные интерактивные сценарии.

## Последний проход

| Сценарий | Результат | Проверено |
| --- | --- | --- |
| Каркас 1280×720 | Пройден | Поле остаётся видимым; панели встроены; горизонтального overflow нет |
| Неподвижная правая стенка | Пройден | Правый край dock не меняется при закрытой панели, панели слева и панели справа |
| Добавление противника | Пройден | Панель «Добавить» открывается слева, жетон сразу появляется на поле |
| Пульт ведущего | Пройден | «Ход», «Ручное решение» и «Состав» не показываются одной длинной лентой |
| Активный участник | Пройден | После начала Хода пульт остаётся на активном участнике |
| Ручной исход | Пройден | Цели, урон, Эффект, заметка, запрос Реакций и прямое применение доступны отдельно |
| Точные параметры | Пройден | Боевые параметры меняются из сворачиваемого редактора и записываются в журнал |
| Ресурсы и часы правил | Защищено кодом и QA | Динамические `ruleResources` и `ruleClocks` выводятся и изменяются с записью в журнал |
| Быстрый бросок | Пройден | Из ручного разрешения одним нажатием открывается конструктор XD6 |
| Настройка компоновки | Пройден | Раздельно, всё справа, всё слева и ручная сторона каждой панели |
| Сохранение компоновки | Пройден | Режим и ручные стороны сохраняются после перезагрузки |
| Карта и управление столом | Пройден | Пространства находятся в «Карте»; копии, восстановление и очистка — в «Столе» |
| Местность, Стены и маркер | Пройден | Созданы на живом поле; редактор не перекрывает карту |
| Ручная перестановка | Пройден | Жетон перемещён; линия пути не появилась; операция записана в журнал |
| Большой бой | Пройден | 11 участников, местность, два сегмента Стены и маркер; overflow отсутствует |
| Мобильный игрок 390×844 | Пройден | GM-команды скрыты, поле доступно, лист открывается поверх поля, нижний dock остаётся доступен |
| Сетевые состояния | Автоматические тесты пройдены | `network-mvp.mjs` и `network-v2.mjs`; реальная двухсессионная Supabase-проверка требует отдельного dev-стола |
