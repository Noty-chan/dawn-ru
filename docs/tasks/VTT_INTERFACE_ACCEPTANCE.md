# Приёмка интерфейса стола DAWN

Дата последнего прохода: 2026-09-03
Ветка: `codex/vtt-interface-redesign`
Основа интеграции: `9016d2f` (`feat(companion): start bilingual LionWing tabletop MVP`)

Этот файл проверяется вместе с `VTT_INTERFACE_REDESIGN_BRIEF.md`. Он фиксирует не обещания по макету, а фактически пройденные интерактивные сценарии.

## Последний проход

| Сценарий | Результат | Проверено |
| --- | --- | --- |
| Каркас 1280×720 | Пройден | Поле остаётся видимым; панели встроены; горизонтального overflow нет |
| Неподвижная правая стенка | Пройден | Правый край dock не меняется при закрытой панели, панели слева и панели справа |

| Передача Хода | Пройден | Пульт предлагает только допустимых по чередованию и ещё не ходивших участников; завершение и передача используют обычные правила, без скрытого ручного обхода |
| Самостоятельный Ход героя | Пройден | Общая настройка рядом с режимом ведения переключает самостоятельный старт и подтверждение Нарратором; сетевой intent повторно проверяет владельца, сторону и доступность Хода |
| Ручной исход | Пройден | Цели, урон, Эффект, заметка, запрос Реакций и прямое применение доступны отдельно |
| Точные параметры | Пройден | Боевые параметры меняются из сворачиваемого редактора и записываются в журнал |
| Ресурсы и часы правил | Защищено кодом и QA | Динамические `ruleResources` и `ruleClocks` выводятся и изменяются с записью в журнал |
| Быстрый бросок | Пройден | Из ручного разрешения одним нажатием открывается конструктор XD6 |
| Настройка компоновки | Пройден | Раздельно, всё справа, всё слева и ручная сторона каждой панели |
| Сохранение компоновки | Пройден | Режим и ручные стороны сохраняются после перезагрузки |
| Карта и управление столом | Пройден | Пространства находятся в «Карте»; копии, восстановление и очистка — в «Столе» |
| Переключение поля из цели | Пройден | Компактная строка открытых пространств показывает число участников и меняет активное поле без закрытия панели |
| Местность, Стены и маркер | Пройден | Созданы на живом поле; редактор не перекрывает карту |
| Ручная перестановка | Пройден | Жетон перемещён; линия пути не появилась; операция записана в журнал |
| Большой бой | Пройден | 11 участников, местность, два сегмента Стены и маркер; overflow отсутствует |
| Мобильный игрок 390×844 | Пройден | GM-команды скрыты, поле доступно, лист открывается поверх поля, нижний dock остаётся доступен |
| Компактный верх стола | Пройден | Раунд и Напряжение сведены к символам; текущее действие и его кнопка занимают ту же строку; заголовок, масштаб и режим ведения убраны в меню |
| Инструменты игрока | Пройден | В обычном состоянии остаются три кнопки по 32 px: выбор, линейка и цель; пустая лента участников не резервирует место |
| Инструменты Нарратора | Пройден | Перестановка остаётся в компактной полевой палитре; местность, Стены, маркеры, разрывы и удаление находятся в панели «Карта» |
| Две рабочие панели | Пройден | Пульт открыт слева одновременно с Правилами или Картой справа; обе панели встроены, а dock остаётся неподвижным у правого края |
| Быстрые Эффекты цели | Пройден | Дублирующий список удалён; кнопки подняты наверх и визуально разделены на усиления и ослабления |

| Настройки рабочего места | Пройден | Доступны стороны каждой панели, независимая ширина слева и справа, плотность интерфейса и видимость ленты участников игрока |
| Переключение версии стола | Пройден | Классический интерфейс включён по умолчанию; новый включается локально в панели «Стол», перезагружает страницу один раз и не меняет интерфейс других участников |
| Совместимость с LionWing | Пройден | Новый стол открывается в английской LionWing-редакции; дополнения и актуальная двуязычная логика из `9016d2f` сохранены |
| Сетевые состояния | Автоматические тесты пройдены | `network-mvp.mjs` и `network-v2.mjs`; реальная двухсессионная Supabase-проверка требует отдельного dev-стола |
