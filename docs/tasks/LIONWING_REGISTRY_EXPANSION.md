# Расширение реестра 33 → 66

Поручение пользователя: добавить 33 Уровня ровно тремя коммитами.
Каждый блок добавляет 11 ручных черновиков. Автоматика и статусы готовности
адаптеров от этого не меняются.

## Блок 1: 33 → 44

Драконоборец I–III, Дуэлянт I–III, Стрелок I–III, Борец I–II.
Изучены цены, окна до выбора целей, Комбо, замены ресурса, изменение костей,
вложенные Раны и сроки. Неопределённые моменты явно записаны в openQuestions.

Источники — английский корпус LionWing и отрисованные PDF-страницы 69–70
(печатные 68–69). SHA-256 исходного текста хранится у каждого Уровня.
Сверка страницы подтверждает полноту извлечения; она не разрешает противоречия
и умолчания канона. Общие определения, на которые ссылаются открытые вопросы,
потребуют отдельного чтения перед реализацией соответствующих адаптеров.

Проверка: `node tools/content/build_lionwing_requirements.mjs --check`.

## Блок 2: 44 → 55

Борец III, Магический мечник I–III, Техник I–III, Несломленный I–III,
Хвастун I. Источники сверены с PDF-страницами 70–71 (печатные 69–70).

Новые требования: расширение допустимых костей без двойной оплаты,
сохранение исходного типа Атаки при добавлении другого типа, история целей
Комбо, сроки до следующего собственного Хода, межсценовый лимит Главы,
запрет получения ресурса, причинная связь особого Сопротивления и его последствий.
Формулировка Гордости одновременно говорит о полных часах и остатке Сцены;
это умолчание не превращено в конкретный алгоритм снятия бонуса.

Проверка реестра пройдена: 55 черновиков, уникальные ID и digest актуальны.

## Блок 3: 55 → 66

Хвастун II–III, Картечник I–III, Боец с парным оружием I–III, Устрашитель I–III.
Источники сверены с PDF-страницей 71 (печатная 70).

Новые требования: изменение размера часов; замена геометрии Атаки; фиксация
цели Шквала и запрет её изменения другими Техниками; чередование вариантов
по экземплярам Стычки; снимок Эффектов до наложения; движение с вытеснением;
создание сущности по причине выведения. У Устрашителя II дальность заменяется
значением Тела: формулировка оригинала не означает прибавку этого значения.

Результат: добавлены 33 черновика, всего 66 из 333, осталось 267.
Три новых коммита содержат по 11 новых ID; существующие 33 записи сохранены.
Это требования для будущих адаптеров, а не расширение работающей автоматики.
Проверка реестра пройдена для каждого блока.
