## Результат

Изменён только адаптивный слой `vtt-cockpit.css`.

- На ширине до 720 px заголовок Сцены складывает текущий этап и кнопки в вертикальную группу. «Цели» и «Карта» получают отдельный ряд и больше не конкурируют с текстом текущего шага.
- Текст текущего этапа и действий переносится по словам; кнопки остаются видимыми и доступными с полным названием.
- Рабочая строка действий больше не растягивается на пустую гибкую строку после карты; действия Нарратора сохраняются видимыми.
- Панель Сцены получает высоту до нижней границы дока, её содержимое прокручивается независимо, а кнопка закрытия остаётся доступной.
- Для 721–900 px текущий этап переносится на две строки, чтобы не сжиматься поверх «Цели» и «Карты».
