# LionWing VIP

Источник: LionWing PDF, страница 127; canonical ID `lionwing.modifier.vip`.

- VIP появляется видимым NPC с `15 + Tier` Здоровья, без Хода. Настройка выполняется при добавлении.
- Когда персонаж на стороне игроков выходит из смежности, Нарратору предлагается переместить VIP в его новую позицию или оставить на месте. Следовать можно один раз за Ход; выбранное положение может совпадать с клеткой сопровождаемого. Поддельное событие сопровождения отклоняется.
- Смежный персонаж игрока или его Призыв защищает VIP от вражеского выбора цели. Обычный союзный NPC не даёт такой защиты. KO VIP выводит из строя только персонажей игроков; этот исход срабатывает и при KO от урона.
- Для существующих карт VIP пока хранится на стороне врагов как защищаемая цель: так старый поиск вражеских целей различает VIP и охраняющих его персонажей. Панель Нарратора управляет им как модификатором Сцены.

Проверка: `tests/lionwing-modifier-vip.mjs`, полный `npm test`.
