# Luna: геометрический предпросмотр и ручной пакет

## Объём

Изменены только UI и поведенческий harness этого блока:

- `apps/companion/lionwing-ui.js`
- `apps/companion/tests/lionwing-geometry-ui.mjs`

`engine`, `lionwing-geometry.js`, `execution`, сетевой путь, `app-core`, `package/index/sw` и пользовательские внешние сцены не изменялись этим блоком.

## Воспроизведение и исправление

До исправления на локальной сцене `lionwing-families` ручное движение строило маршрут без изменения `Scene`. После ухода курсора с `scene-board` старый обработчик `mouseleave` очищал `scenePreviewCells` и классы `.preview`, хотя `lwGeometryPreview` оставался активным. Поэтому маршрут исчезал, а старый план продолжал ждать подтверждения.

Предпросмотр теперь хранит исходное намерение, подготовленное событие, версию и устойчивую идентичность сцены. Версия используется для stale-проверки, а идентичность сцены отделена от заменяемого объекта `Scene`, поэтому обычный канонический commit с новым объектом может пересчитать маршрут. Смена выбранного участника, пространства или сцены очищает старый план.

При включённом «Собирать операции перед применением» кнопка маршрута называется «Добавить движение в пакет» и отправляет проверенный `geometry-move` через существующий `lwSubmit`; участник не перемещается до применения пакета. Обычный предпросмотр подтверждается только через `previewEvents` и общий `commitSceneEvents`. Отмена очищает локальный выбор, маршрут и подсветку без изменения `Scene`. Подтверждение и добавление явно доступны только Нарратору.

Перед подтверждением выполняется структурная `DAWN_LIONWING_GEOMETRY.revalidatePlan`, если она загружена, затем read-only `LionwingEngine.previewEvents`. Устаревший план не отправляется: UI пересчитывает маршрут, показывает «Сцена изменилась: маршрут пересчитан. Проверьте и подтвердите обновлённый маршрут» и требует второго нажатия. Причины остановки маршрута отображаются по-русски; идентификатор `difficult-terrain` в UI не показывается.

Для совместимости со старым `mouseleave` добавлен capture-слушатель, который после завершения события восстанавливает подсветку активного маршрута через microtask. Он не останавливает и не меняет чужой обработчик. В `app-scene-events.js` прежний обработчик по-прежнему очищает общий preview-набор; отдельная правка этого файла не нужна.

## Проверка

- `node apps/companion/tests/lionwing-geometry-ui.mjs` — проходит проверки успеха, отмены, добавления в пакет, stale-пересчёта через отдельный commit path с заменой объекта `Scene`, второго подтверждения, роли, смены выбора/пространства/сцены, русской причины и сохранения подсветки.
- `node --check apps/companion/lionwing-ui.js` — синтаксис проходит.
- `git diff --check -- apps/companion/lionwing-ui.js apps/companion/tests/lionwing-geometry-ui.mjs` — проходит.
- `npm --prefix apps/companion run test:families` — существующие targeted-проверки foundations, geometry, geometry-commit и effects проходят.
- `npm --prefix apps/companion test` — текущий общий QA-набор завершился успешно; это не расширяет заявленный объём реализации этого UI-блока.
- В настоящем браузере Playwright-сессии `lionwing-families` на `http://127.0.0.1:8876/apps/companion/`: маршрут был подготовлен вручную, уход с поля сохранил подсветку, «Добавить движение в пакет» оставил координаты героя `0:1` и добавил `geometry-move` в несохранённый пакет, версия сцены осталась прежней; ошибок консоли нет.

## Ограничения для следующего ревью

Backend по-прежнему строит вложенные последовательные маршруты по исходной геометрии; UI не скрывает это ограничение и не обходит stale-защиту. Окна сегментов/последовательных участков остаются отдельным этапом работ. Полнота семейства возможностей этим блоком не заявляется.
