# LionWing Collateral

Источник: LionWing PDF, страница 126; canonical ID `lionwing.modifier.collateral`.

- При развёртывании Нарратор выбирает пустые клетки в количестве `ceil(1.5 × число персонажей игроков)`. Каждая жертва имеет `5 + Tier` Здоровья, не получает Хода и видна на поле.
- Часы опасности получают по сегменту на персонажа игрока. KO каждой жертвы заполняет один сегмент; полные часы выводят из строя персонажей игроков, представляя поражение в бою. Союзные NPC и служебные токены не меняют размер часов и не входят в исход поражения.
- Смежный персонаж игрока или его Призыв защищает жертву от вражеского выбора цели. Обычный союзный NPC её не защищает.
- Персонаж игрока может безопасно убрать смежную жертву Взаимодействием за 1 ОД и успешным испытанием Духа `1 + Tier`. Число костей берётся из Духа, а успешное спасение не заполняет часы.

Проверка: `tests/lionwing-modifier-collateral.mjs` и полный `npm test`.
