# LionWing Isolation — первый исполняемый модификатор

Источник: новый PDF, PDF-страницы 125 и 127 (печатные 124 и 126), canonical `lionwing.modifier.isolation`. Правило не входит в 122 правила обычных NPC. Статус: **runtime connected, UI wired**, браузерная и сетевая приёмка `not-run`; миграция старых сохранений и остальные 11 профилей остаются отдельной работой.

## Mechanics brief

| Уровень | Требование |
| --- | --- |
| Источник | `Scene Modifier; Deploy alongside the Scene`, затем `When this is Attached, indicate a player character`. |
| Решение пользователя | При подготовке боя прикрепить Изоляцию к одному NPC Host; затем указать игрока-центр. Считать её особенностью этого Host. Пассив прекращается, когда Host Knocked Out. Это уточнение при конфликте строк PDF. |
| Round end | Всем другим живым персонажам игроков в пределах 3 клеток от центра нанести `ceil(((2 + Tier) × число живых игроков) / число получателей)` урона. Сначала рассчитывается полный набор получателей; центр не получает урон. После эффекта выбрать другого игрока. |
| Общий закон | PDF-страница 35: дроби округляются вверх. |

Пример: Tier 2 и четыре живых игрока дают пул 16. Два получателя в радиусе получают по 8. Контрпример: legacy `6(+1)` дал бы другой пул. Изоляция без живого Host не наносит урон и не открывает новый запрос.

`LionwingTable.modifiers` отделяет 12 canonical modifiers от 41 NPC. В выборе сцены сейчас доступна Изоляция как первый подключённый профиль. `prepareModifierConfigure` через общий writer проверяет Host, игрока и неизменность Host после выбора; `round.end` остаётся в LionWing lifecycle, затем узкий мост запускает пассив и запрос переназначения. Тест `tests/lionwing-modifier-isolation.mjs` проверяет создание настройки, чужую цель, урон и деление, новый центр, запрет ранней смены и KO Host. Legacy тест `tests/enemy-modifiers.mjs` и полный `npm test` проходят.

Ограничения текущего среза: нет автоматической миграции сохранённых `enemy.modifier.*`, проверки в живом браузере и двух сетевых клиентах. Подсчёт игроков при уже KO участнике принят как число живых игроков Сцены; если нужен исходный состав боя, потребуется явный snapshot на Deployment.
