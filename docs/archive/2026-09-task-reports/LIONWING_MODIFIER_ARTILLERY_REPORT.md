# LionWing Artillery — область и конец Раунда

Источник: новый PDF, страница 126 (печатная 125), canonical `lionwing.modifier.artillery`. Статус: **runtime connected, UI wired**, браузерная и сетевая приёмка `not-run`; профиль не выдаётся за E2E-сертифицированный.

## Mechanics brief

После Развёртывания Нарратор выбирает одну из четырёх форм: две бесконечные несмежные линии, область 3×3, область 2×5 или все клетки края поля. Область можно расположить где угодно на поле. В конце Раунда каждый противник в указанной области получает `[Tension]` урона по значению завершившегося Раунда; затем Нарратор выбирает следующую область той же формы.

Пример: при Напряжении 3 внутри области 3×3 персонаж получает 3 урона. LionWing затем повышает Напряжение до 4; использовать 4 для уже завершающегося Раунда было бы ошибкой. Контрпример: смена формы с 3×3 на 2×5 после первого срабатывания нарушает выбор формы при Развёртывании.

`LionwingTable.modifiers` сохраняет canonical ID отдельно от обычных NPC. Выбор профиля и панель области доступны Нарратору. `modifier.configure` проверяет точную форму, клетки, выбранный режим и запрещает раннюю смену. LionWing `round.end` сохраняет `endedTension`, затем узкий мост применяет урон и открывает запрос новой области. Тест `tests/lionwing-modifier-artillery.mjs` проверяет неверную геометрию, фиксированную форму, урон до повышения Напряжения, недоступную внешнюю цель и обновление области. Legacy `tests/enemy-modifiers.mjs` и полный `npm test` проходят.

Не проверено: браузерная разметка всех четырёх форм, сетевое переподключение, миграция старых LionWing-сохранений и взаимодействие с Terrain/Compound.
