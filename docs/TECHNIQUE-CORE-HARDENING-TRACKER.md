## Общая матрица устойчивости

Каждая строка должна ссылаться на прямой тест или общий parametrized harness для:

- stale prompt/version и изменившейся Сцены;
- KO владельца/цели между prompt и ответом;
- смены controller/ownership;
- duplicate response/event и idempotent replay;
- отмены до оплаты без утечки ресурса;
- занятой, удалённой, пустой и неканонической клетки;
- reconnect/import в середине typed continuation;
- forged network intent/roll/target и authoritative re-derivation;
- стабильного порядка одновременных triggers;
- Scene/Round/Turn reset и срока эффектов/сущностей.

## Финальный gate

`npm run map`, `npm run readiness`, `npm run docs:rules`, полный `npm test` и
`git diff --check`. После этого — push только `codex/technique-core-hardening` и
PR только в `codex/audit-fixes-for-main`. Evidence/certified не редактируются.
