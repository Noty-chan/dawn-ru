# Записи гаджетов в листе героя

Изолированный модуль `hero-gadgets.js` хранит предметы героя и считает их Ранги.
Он не меняет Scene, сетевой протокол и сущности боевого Стола.

В schema 2 добавлено необязательное поле:

```json
{
  "gadgets": [{
    "id": "sensor",
    "status": "active",
    "ability": {
      "enabled": true,
      "name": "Датчик силы",
      "rank": 1,
      "words": {
        "verbs": ["ability.en.verbs.perceive"],
        "nouns": ["ability.en.nouns.magic"],
        "conditions": []
      }
    }
  }]
}
```

`ability` проходит обычную нормализацию Способности, включая описание,
пользовательские слова, X и специализации. Допускается до 30 записей.
`destroyed` сохраняет формулу и не расходует Ранги; восстановление возвращает
предмет в расчёт. Удалять можно разобранную запись.

Дар «Технарь» включает редактор, раздел листа и источники кубиков.
При снятии Дара данные сохраняются, но становятся неактивными в интерфейсе
и расчёте. Резерв Дара оплачивает первые 3 Ранга совокупной стоимости активных
гаджетов, превышение расходует общий бюджет. Гаджеты не являются Навыками.

Старое `mods.gadgetSpent` сохранено как Ранги предметов без отдельных записей
и прибавляется к новым. При переносе старых предметов в записи нужно уменьшить
ручную сумму, чтобы не получить двойной расход. Автоматически обнулять её нельзя:
названия и формулы неизвестных предметов в старом формате отсутствуют.

Редактор использует ключ `gadget:<id>` и общий редактор Способности с уникальными
DOM id. Изменение предмета не меняет основную/осквернённую Способность.
JS/CSS подключены в index, service worker и списке QA.

Проверки:

- `npm run test:hero-gadgets` — бюджеты, разбор, сериализация, отсутствие Дара,
  независимость редакторов, безопасные id и совместимость старых листов.
- `npm run test:hero-sheet-view` — существующий лист/режимы/мост последствий/локализация.
- `node tests/syntax.mjs` и `node tests/qa.mjs` — подключение и общие инварианты.

Открытая граница: Инструменты пока не умеют выбирать эти гаджеты. Работа с
физическими предметами в Scene также требует отдельного контракта; подробности
в [журнале UI](../../docs/tasks/COMPANION_UI_AUDIT_2026-10-05.md).
