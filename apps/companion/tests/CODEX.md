# Тесты Companion

Здесь находятся браузерные и модульные проверки стола. Тесты должны проверять наблюдаемое поведение и инварианты ядра, а не внутреннюю форму объектов без необходимости.

Для новой общей механики добавляйте хотя бы один успешный и один пограничный сценарий. Для техники проверяйте расход ресурсов, допустимость целей, отмену/прерывание и итоговые события. Запускайте весь набор через `npm test`.
