# Путь свободного броска

Открыть `index.html` напрямую или через обычный локальный static server. Нет установки зависимостей. Это foundation для оценки UX, не production-ready механика.

Проверочный путь: выбрать Нику → Навык Взлом → гаджет → Связь Ира → проверить формулу → показать запрос → демонстрационный провал → Ва-банк или Риск → завершить → открыть/очистить свернутые записи. Нажать «Влияние = 0» для объяснимого запрета; сменить героя на Льва для проверки условных функций. Вкладки идут Герой → Инструменты → Стол → Правила → Справочник.

Изменения героя и сброс намеренно закрывают демонстрационный результат. Все данные только в памяти; перезагрузка их сбрасывает. Сеть, передача гаджетов, реальные кубики, автоматизация Связей, правила исключительных Даров и полноценные остальные разделы не реализованы. Состав пула не проверяет нарративную релевантность: её подтверждает стол.

Проверки: `node --check flow.js` проходит. CUA в отдельной скрытой вкладке на 8771: выбран гаджет+Связь, формула 8D6; запрос блокирует редактирование условий; фиксированный провал; при 0 Влияния Ва-банк disabled; Риск меняет ресурсы один раз и закрывает Ва-банк; герой без Технаря не видит собственного гаджета; Ва-банк списывает 1 Влияние; завершение и очистка свернутой истории работают. Viewport не менялся, узкий экран и keyboard-only не проверены. Финальный guard повторного завершения проверен синтаксически после browser QA. Production tests не запускались: production не менялся.
