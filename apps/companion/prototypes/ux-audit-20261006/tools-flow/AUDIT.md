## Foundation

Изолированный buildless прототип. Не импортирует production scripts, не читает реальные листы, не использует localStorage, service worker, sync, Supabase. Два демонстрационных героя; числа существуют только в памяти вкладки. Навигационные разделы, кроме Инструментов, — явно подписанные заглушки. Фиксированный провал и фиксированный итог Ва-банк — **mock**, не реализация правил. Базовый Стресс/Влияние — демонстрационная модель для пути, не проверка всех источников/участников выплаты.

Терминология: dawn-ru-translation glossary/style; Нарратор. Канон: LionWing canonical core-rules/outlooks. Для production нельзя механически переносить нынешний алгоритм Ва-банк: нужно отдельно сверить полный печатный текст и последствия; canonical All Out summary недостаточен для реализации.
