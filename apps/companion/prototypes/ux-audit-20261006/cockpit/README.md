# Foundation: изолированный прототип пульта

Buildless: открыть index.html. Никаких зависимостей, сетевых запросов, localStorage, production imports или записей сохранений. Навигация: Герой → Инструменты → Стол → Правила → Справочник; ссылки Герой/Инструменты возвращают к общей папке черновиков, последние два раскрывают контекст внутри страницы.

Проверочный сценарий: выбрать Цепь → врага А на карте либо в списке → увидеть 1 ОД → отменить, проверить сохранение 3 ОД → повторить и подтвердить. После подтверждения демо показывает 2 ОД и блокирует повторную экипировку Цепи в этом демо-Ходу. Сброс возвращает начало. Для Древка выбрать соответствующую расстановку и обе цели; для Клинка сначала клетку ○, затем врага А. Выбор несовместимой расстановки показывает причину недоступности.

Демоданные: Рааша Шаадрин, 3 ОД, враги А/Б, позиции, заранее подготовленные допустимые клетки. Автоматика отключена: нет броска, реакций, event reducer, версии сцены, реального movement query, урона, эффектов, сетевой синхронизации и сохранения. Кнопка подтверждения только изменяет локальную демо-модель и журнал. Клинок визуально отмечает место перемещения; реальный токен не переносит. Это UX foundation, не production-ready двигатель.

Проверки: прочитаны screenshot, CODEX, ARCHITECTURE, LOCALIZATION, TECHNIQUE-AUTOMATION, TECHNIQUE-REVIEW и canonical LionWing. Синтаксис JS проверяется node --check app.js. Browser QA, production tests и полноценные механические тесты не выполнены; эта граница намеренная для изолированной UX-заготовки. Навыки: Sites (local-only), computer-use прочитан для допустимого пути проверки; browser automation не использована.

Выполнена также node VM проверка демо-модели с минимальным DOM mock: отмена без оплаты, Цепь и списание 1 ОД, запрет повторной экипировки, Клинок требует destination до цели, Древко требует обе цели. Все assert прошли. Это проверка JS-переходов, не браузерного layout или реального движка.
