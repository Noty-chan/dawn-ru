## Решение и границы

Пульт — пошаговый черновик действия: режим → цель/клетка → подтверждение. Карта остаётся рядом. Повторное нажатие цели снимает выбор; Escape и кнопка отменяют без расхода. Причины недоступности написаны текстом и доступны без hover. Полные правила раскрываются по запросу. Закреплённый итог сообщает инициатора через заголовок, стоимость, цели, готовность.

Цена 1 ОД взята из canonical/core-rules.json:309–317; условия трёх Вооружений — canonical/archetypes/vagabond.json, vagabond.master-at-arms I, PDF стр.79. Быстрая не означает бесплатная. Мы не моделируем модификаторы цены. Для реального внедрения цена, eligibility, расстояния, перемещения и эффекты должны поступать из existing engine prepare/query, а подтверждение — через текущую событийную границу. Прототип не заменяет эти контракты.
