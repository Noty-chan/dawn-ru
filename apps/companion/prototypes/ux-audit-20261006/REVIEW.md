## Перекрёстный аудит и исправления

Пульт → проверка агентом оболочки: фокус удалялся при выборе; 35 клеток входили в Tab. Исправлены стабильные ключи фокуса, Tab только по доступным целям/клетке. Клинок переводит фокус к клетке, затем к цели. На 390px root подтвердил, что fixed итог выше резерва страницы; резерв теперь зависит от реальной высоты через ResizeObserver.

Оболочка → проверка агентом Tools: вложенная справка теряла исходный маршрут, старый фильтр мог скрыть адресное правило, результат броска исчезал при возврате, перерисовка теряла фокус. Все четыре исправлены локально.

Три компоновки → проверка агентом оболочки: текст/Риск запроса терялся после настройки пула, смена роли удаляла запрос, фокус не переходил к ответу/итогу. Исправлено. Root дополнительно поправил сохранение числа цели при вводе и переполнение ресурсов карточки группы на телефоне.

HUD → проверка агентом Tools: Apply терял фокус при обновлении; меньше 44px видимого поля нарушали clamp. Исправлены обе регрессии. Root обнаружил наследуемые две колонки внутри action buttons и подтвердил исправление в браузере.

Путь броска → проверка агентом пульта: P1/P2 в заявленном mock-flow не найдено. Модельные проверки включали отсутствие повторной оплаты, исключение Риск/Ва-банк, отсутствие Влияния, завершение и смену героя. Root устранил горизонтальное переполнение формы на 390px.

## Браузерная проверка root

CUA, действующие DOM-контролы; собственная тестовая сцена на `127.0.0.1:8773`, отдельное пустое хранилище. Пользовательские листы и комната не импортировались. Убийца по своему правилу отсутствует на поле; для HUD использован Страж.

- Все три Tools: выбор героя/источников, бросок XD6 и история, Ва-банк со списанием 1 Влияния, исчезновение гаджета при выключении особенности Нееля.
- Пульт группы: свой текст и Риск → изменение цели → запрос → смена ролей → ответ. Условия остаются в запросе.
- Пульт: Цепь → цель → отмена оставляет 3 ОД; Древко → две цели → подтверждение оставляет 2 ОД; keyboard Enter сохраняет фокус цели.
- Оболочка: Реакция → полные Правила → повторное чтение → возврат к Столу; Tools итог → справка → возврат сохраняет результат.
- HUD: right-click Стража; `-5` + Escape оставляет 25/25; `-5` + Apply даёт 20/25; просмотр Профиля сохраняет выбранную цель. Скриншот рабочего меню сохранён.
- Проверены ширины 1440 и 390px. В owned hidden CUA вкладке viewport override применяется корректно; открытая app-preview вкладка имеет собственный размер. Скриншоты отрисованы браузером, не нарисованы вручную.

Root не объявляет выполненными: полный keyboard-only проход всех макетов, screen reader, передача гаджета другому герою, реальная печать/импорт, все Дары и сетевой сценарий Нарратор + два игрока.
