# Три черновика Инструментов · 6 октября 2026

Статус: **foundation**. Изолированные HTML/CSS/JS-макеты; рабочий компаньон их не загружает. Базовый коммит: e3e6f182b100d3899ee274f0f7d732483d179570.

Открыть через HTTP: `index.html?variant=1`, `?variant=2`, `?variant=3`.

- **01 — Рабочее место.** Герой и Атрибут слева, сборка и результат в центре, журнал и часы справа. Для постоянного использования одним игроком.
- **02 — Строка действия.** Компактная страница с источниками броска в одной строке, без полной копии листа. Для спокойного интерфейса и чтения.
- **03 — Пульт группы.** Ресурсы двух героев сверху, задачи и Атрибут слева, запрос Нарратора рядом с броском, общий журнал справа.

Общее: порядок вкладок Герой → Инструменты → Стол → Правила → Справочник. Изменение героя, Атрибута, одного Навыка, Способности/гаджета и Связи; Преимущество/Помеха, цель, XD6, Ва-банк, запрос и ответ, часы. Гаджеты показываются только для демонстрационного Нееля с соответствующей особенностью; переключатель проверки находится за пределами основного игрового потока.

Зависимости: чистые `DAWN_LOGIC.rollXd6` и `challengeOutcome` из `../../logic.js`; шрифт Golos Text (при отсутствии сети системный запасной). Стандартные теги Связей. Имена, состав листов и гаджетов иллюстративные и не являются новым экспортом перенесённых героев. Бросок случайный; снимки отличаются.

Моки: герои, ресурсы, отправитель/получатель запроса, часы, журнал. Только память страницы; никакой записи в настоящее хранилище или сеть. Переключение роли показывает обе стороны запроса на одном устройстве.

Not-run: многопользовательская синхронизация, перезагрузка с восстановлением данных, полный набор Даров/крючков XD6, редактирование и экспорт листа. Для принятия компоновки не требуется считать макет рабочим столом.

Проверка браузером и замечания перекрёстного аудита фиксируются в общем журнале `../ux-audit-20261006/REVIEW.md`.

По уточнению пользователя все варианты используют текущую production-палитру app.css. Светлая/зелёная пробная гамма отменена; сравниваем только структуру и поведение.
