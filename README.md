# DAWN RU

Неофициальная русская локализация **DAWN: The RPG** Джоэла Врёгденхила, инструменты сборки книги, игровой компаньон и учебные материалы. Текущая разработка компаньона ведётся для редакции LionWing; прежняя редакция 0.9 сохраняется для старых игр.

Текущая версия: **0.9.0**.

Сайт проекта: **https://noty-chan.github.io/dawn-ru/**

## Структура

- `source/original/` — исходный англоязычный PDF.
- `source/translation/` — русский текст прежней редакции 0.9, глоссарий и редакторский стиль.
- `source/editions/dawn-en-lionwing-cb2f8e67/canonical/` — структурированный канон LionWing.
- `source/editorial/` — история редакторских сверок.
- `tools/layout/` — сборщик и ресурсы русской верстки.
- `apps/companion/` — автономный компаньон 2: сборка героя, игровой стол, XD6, часы и справочник.
- `media/tutorials/` — 13 адаптивных объясняющих анимаций с единым проигрывателем.
- `release/` — только канонические релизные файлы.
- `build/` — воспроизводимые промежуточные результаты.
- `archive/` — старые сборки, пакеты и экспериментальные материалы.
- `docs/tasks/README.md` — действующие точки входа в проектную документацию; `docs/archive/` — исторические отчёты и снимок уборки веток.

## Сборка книги

Требуется Python 3.12 или новее.

```powershell
python -m pip install -r requirements.txt
python tools/layout/build_pilot_pdf.py final
```

Результат: `release/DAWN-RU-v0.9.0.pdf`.

## Обновление данных компаньона

```powershell
python apps/companion/build_data.py
cd apps/companion
npm test
```

Данные прежней редакции компаньон собирает из `source/translation/`; для LionWing используется отдельный корпус. Для запуска без установки откройте
`apps/companion/index.html`. Он поддерживает старые сохранения, несколько героев, печать и переносимый JSON.
Карта модулей и правила изменения порядка скриптов описаны в `apps/companion/ARCHITECTURE.md`.

## Учебные анимации

Откройте `media/tutorials/00_оглавление.html`. Каждый урок можно ставить на паузу,
перезапускать и перелистывать; холст корректно масштабируется от телефона до 1920×1080.
