# LionWing canonical corpus

Это основной источник английского текста для разработки сайта и нового русского
перевода. Открывать PDF для обычной работы не требуется.

- `archetypes/*.json` — Архетипы и полный английский текст 111 Техник.
- `outlooks.json` — Мировоззрения и Дары.
- `ability-words.json` — слова Способностей, стоимость и символы.
- `builder-reference.json` — короткие карточки справочника создания персонажа.
- `core-rules.json` — боевое ядро, Эффекты и базовые Действия LionWing с
  механическими полями и привязкой к страницам.
- `id-map.json` — связь со стабильными ID работающей версии 0.9.
- `manifest.json` — состав корпуса и контрольные количества.

Файлы генерируются `tools/content/build_lionwing_companion.py`; ручные исправления
следует оформлять как проверенные изменения в `../changes.json`, иначе следующая
генерация их перезапишет. Русская 0.9 — только база совместимости и регрессии. Её
формулировки и реализация механики не являются каноном для LionWing.
