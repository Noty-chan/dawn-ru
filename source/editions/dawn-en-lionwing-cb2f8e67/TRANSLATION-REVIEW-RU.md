# Редакторская сверка русского LionWing

Этот файл отделяет изменение английского канона от редакторской правки русского текста. Стабильные ID не меняются при переименовании техники.

## Правила сверки

- Если английское название не изменилось, сохраняем устоявшееся русское название 0.9, кроме явных ошибок.
- Если английское название изменилось, переводим новое название и отмечаем старое здесь.
- Старый русский текст используется только как словарь терминов; механика переводится заново с актуального английского.
- Сомнительный художественный вариант не выдаётся за утверждённый: он остаётся в списке на редактуру.

## Требует следующего редакторского решения

| ID / термин | Текущий вариант | Что проверить |
| --- | --- | --- |
| `bulwark.runic-retribution` / `Mollycoddler` | Нянька | «Наседка» точнее передаёт чрезмерную, удушающую опеку, но заметно меняет тон |
| `bulwark.stalwart-sentry` / `Spotlight` | софит | Возможно, «световое пятно» яснее обозначает клетку, а не прибор |
| `altruist.heavenly-saint` / `Compassion` | Сострадание | Проверить согласование названия ресурса со «Сострадательным мудрецом» во всём интерфейсе |
| `vagabond.cunning-fighter` / `Cavalcabo` | Cavalcabo | Уточнить, является ли это именем школы и нужна ли транслитерация «Кавалькабо» |
| `vagabond.egomaniac` / `sho'vah` | шо'ва | Сверить официальную передачу внутриигрового термина |
