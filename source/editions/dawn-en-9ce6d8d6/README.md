# DAWN 0.9 English comparison source

`extracted-comparison-source.json` содержит английские тексты 107 Техник,
Мировоззрений, Даров и слов Способностей старой редакции. Этот файл нужен только
для воспроизводимого сравнения с LionWing.

Он не является источником нового русского перевода и не влияет на работающую
русскую 0.9. Новый перевод всегда строится по английскому корпусу LionWing.
